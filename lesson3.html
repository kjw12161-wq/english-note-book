Life Is a Sum of Choices

끊어읽기 + 출제 포인트 · 내신 필수 30문장

어떤 투표 방식을 선택하느냐에 따라 결과가 달라질 수 있다는 흥미로운 상황을 통해 세 가지 투표 방식(다수결, 대안 투표제, 콩도르세 방법)을 소개합니다.

핵심 축: 「개인적 결정 ↔ 집단적 의사결정」 · 「단순함(결함) ↔ 복잡함(정확성)」

주요 어법: 의문사+to부정사 · 동명사의 의미상 주어 · 복합관계대명사 · with 분사구문 · 수일치

Ⅰ. 도입 — 집단적 의사결정과 투표
#1

We make many personal choices / in our lives, / from who to have lunch with / to what career to pursue.

→ 우리는 많은 개인적인 선택을 한다 / 우리 삶에서, / 누구와 점심을 먹을지부터 / 어떤 진로를 추구할지까지.

★ 핵심 포인트: from A to B = A에서 B까지 (의문사 + to-V 형태가 명사구로 쓰여 전치사의 목적어 역할)
#2

However, there are many situations / where we must make decisions as a group.

→ 그러나, 많은 상황들이 있다 / 우리가 집단으로서 결정을 내려야 하는.

★ 핵심 포인트: where = 관계부사 (뒤에 완전한 문장이 오며 선행사 situations를 수식 / in which로 바꿀 수 있음)
#3

Group decision-making is not as simple / as our personal choices, / as it involves numerous voices / with differing opinions.

→ 집단의 의사결정은 간단하지 않다 / 우리의 개인적인 선택만큼, / 그것이 수많은 목소리를 포함하기 때문에 / 다른 의견을 가진.

★ 핵심 포인트: not as ~ as = ~만큼 ...하지 않은 (원급 비교) / 접속사 as = ~때문에 (= because, since)
#4

Voting is often used / to make group decisions fairer and more efficient, / and various voting methods have been developed / over time.

→ 투표는 종종 사용된다 / 집단의 결정을 더 공정하고 효율적으로 만들기 위해, / 그리고 다양한 투표 방식들이 개발되어 왔다 / 시간이 흐르면서.

★ 핵심 포인트: be used to-V = ~하는 데 사용되다 / make + O(group decisions) + O.C(fairer and more efficient)
#5

The following story illustrates / how these different voting methods work.

→ 다음 이야기는 보여 준다 / 어떻게 이 다른 투표 방식들이 작동하는지.

★ 핵심 포인트: how + S + V = 간접의문문 (의문사 + 주어 + 동사 어순으로 명사절 역할)
Ⅱ. 학생회의 고민 — 새로운 투표 방식의 도입
#6

The members of the Greenville High School student council / needed to decide / how to raise money / for children in need.

→ Greenville 고등학교 학생회 임원들은 / 결정할 필요가 있었다 / 어떻게 돈을 모을지를 / 어려운 아이들을 위해.

★ 핵심 포인트: how to-V = 어떻게 ~할지 (= how they should raise)
#7

When they asked for advice / from Ms. Akers, the council’s advisor, / she encouraged them / not to use the familiar voting method, / but to try something different instead.

→ 그들이 조언을 구했을 때 / 학생회 고문인 Akers 선생님에게, / 그녀는 그들에게 권장했다 / 익숙한 투표 방식을 사용하지 말고, / 대신 뭔가 다른 것을 시도해 보라고.

★ 핵심 포인트: encourage + O + to-V (목적격 보어) / not A but B = A가 아니라 B (not to use ~ but to try ~ 병렬 구조)
#8

After doing some research, / the council members decided / to try three different voting systems: / the first-past-the-post method, the alternative vote method, / and the Condorcet method.

→ 약간의 조사를 한 후에, / 학생회 임원들은 결정했다 / 세 가지 다른 투표 방식을 시도해 보기로 / 다수결 방식, 대안 투표제, / 그리고 콩도르세 방법.

★ 핵심 포인트: After doing = 전치사 + 동명사 (또는 접속사를 생략하지 않은 분사구문)
#9

The entire council was curious / to find out / if the different methods would yield / different results.

→ 학생회 전체는 궁금했다 / 알아보고 싶어서 / 다른 방식들이 산출할지 / 다른 결과를.

★ 핵심 포인트: if = ~인지 아닌지 (명사절을 이끄는 접속사 = whether)
#10

Each of the 20 council members / was given a voting slip / and instructed to write down the options / in order of preference.

→ 20명의 학생회 임원 각각은 / 투표용지를 받았다 / 그리고 선택지들을 적으라고 지시받았다 / 선호하는 순서대로.

★ 핵심 포인트: was given ~ and (was) instructed = 수동태 동사 병렬 / Each of + 복수명사 + 단수동사(was)
#11

For example, / if the charity concert was their first choice, / followed by the bake sale and the art show, / they would write CBA.

→ 예를 들어, / 자선 콘서트가 그들의 첫 번째 선택이고, / 베이크 세일과 미술 전시회가 그 뒤를 잇는다면, / 그들은 CBA라고 쓸 것이다.

★ 핵심 포인트: followed by = ~가 뒤따르는 (분사구문) / if 가정법 과거 형태 반영
Ⅲ. The First-Past-The-Post Method (다수결 / 최다 득표제)
#12

Voters are given several options, / and whichever gets the most first-preference votes / wins.

→ 유권자들에게는 여러 선택지가 주어진다, / 그리고 가장 많은 1순위 표를 얻는 것이 무엇이든 / 이긴다.

★ 핵심 포인트: whichever = 복합관계대명사 (명사절을 이끌며 문장의 주어 역할 = anything that)
#13

Neither the second nor third preference / matters at all, / so they are ignored.

→ 2순위도 3순위도 / 전혀 중요하지 않다, / 그래서 그것들은 무시된다.

★ 핵심 포인트: Neither A nor B = A도 B도 아닌 / matter = 중요하다 (자동사)
#14

The student council quickly determined / that the winner would be option C, / the charity concert.

→ 학생회는 빠르게 결론지었다 / 우승자는 C안이 될 것이라고, / (즉) 자선 콘서트.

★ 핵심 포인트: that = 명사절 접속사 (determined의 목적어) / option C와 the charity concert는 동격
#15

It is possible / to win a vote / without the support of the majority.

→ 가능하다 / 투표에서 이기는 것이 / 다수의 지지 없이.

★ 핵심 포인트: It (가주어) ~ to win (진주어)
#16

However, only 8 out of 20 council members / chose the charity concert / as their first preference, / which equaled 40% of the total votes.

→ 하지만, 20명의 학생회 임원 중 겨우 8명만이 / 자선 콘서트를 선택했다 / 그들의 1순위로, / 그리고 그것은 전체 표의 40%와 같았다.

★ 핵심 포인트: , which = 계속적 용법의 관계대명사 (앞 문장의 내용 일부를 선행사로 받음 = and it)
Ⅳ. The Alternative Vote Method (대안 투표제)
#17

Next, / the council members examined the votes / using the AV method, / and they soon realized / that there would be a different result.

→ 다음으로, / 학생회 임원들은 표를 검토했다 / 대안 투표제(AV) 방식을 사용하여, / 그리고 그들은 곧 깨달았다 / 다른 결과가 나올 것이라는 것을.

★ 핵심 포인트: using = 현재분사 구문 (~을 사용하여)
#18

For an option to win in the first round, / it needs to get / more than 50% of the first-preference votes.

→ 한 선택지가 첫 번째 라운드에서 이기려면, / 그것은 얻어야 한다 / 1순위 표의 50% 이상을.

★ 핵심 포인트: For an option = to win의 의미상 주어 (to부정사 앞에 for+명사)
#19

Option A, the art show, / received the fewest first-preference votes, / with only 5 council members voting for it.

→ A안인 미술 전시회는, / 가장 적은 1순위 표를 받았다, / 겨우 5명의 임원만이 그것에 투표한 채로.

★ 핵심 포인트: with + 명사 + 분사(-ing) = ~가 …한 채로 (부대상황 분사구문 - members가 직접 투표하므로 능동의 voting)
#20

Therefore, / option A was eliminated, / and the 5 council members’ votes were redistributed / based on their second preferences.

→ 따라서, / A안은 탈락되었다, / 그리고 5명의 임원의 표는 재분배되었다 / 그들의 2순위에 기반하여.

★ 핵심 포인트: was eliminated / were redistributed = 수동태
#21

It sometimes allows / second-preference votes to have a greater influence / than first-preference votes.

→ 그것은 때때로 허용한다 / 2순위 표가 더 큰 영향력을 가지도록 / 1순위 표보다.

★ 핵심 포인트: allow + O + to-V (목적격 보어) = O가 ~하는 것을 허용하다
Ⅴ. The Condorcet Method (콩도르세 방법)
#22

This method involves comparing / the voters’ preferences / between each possible pair of options.

→ 이 방식은 비교하는 것을 포함한다 / 유권자들의 선호도를 / 각각의 가능한 선택지 쌍 사이에서.

★ 핵심 포인트: involve + ~ing (동명사를 목적어로 취함)
#23

Through this method, / the student council discovered / that its members preferred option A to option B / by a count of 11 to 9.

→ 이 방식을 통해, / 학생회는 발견했다 / 임원들이 B안보다 A안을 더 선호한다는 것을 / 11대 9의 수로.

★ 핵심 포인트: prefer A to B = B보다 A를 더 선호하다 (to는 전치사)
#24

In other words, / 11 people preferred A to B, / voting either ABC, ACB, or CAB.

→ 다시 말해서, / 11명이 B보다 A를 더 선호했다, / ABC, ACB, 또는 CAB 중 하나로 투표하면서.

★ 핵심 포인트: voting = 현재분사 구문 (~하면서) / either A or B = A와 B 둘 중 하나 (여기서는 3개 중 하나)
#25

As option A, the art show, / was preferred to both of the other options, / it would be considered the winner.

→ A안인 미술 전시회가, / 다른 두 선택지 모두보다 더 선호되었기 때문에, / 그것이 우승자로 여겨질 것이다.

★ 핵심 포인트: As = ~이기 때문에 / was preferred to = 수동태 / be considered + 명사 = ~로 여겨지다(5형식의 수동태)
#26

The Condorcet method’s weakness is / that, along with being complex, / it sometimes fails to select a winner.

→ 콩도르세 방법의 약점은 ~이다 / 복잡하다는 것과 더불어, / 때때로 우승자를 선택하는 데 실패한다는 것.

★ 핵심 포인트: that = 명사절 접속사 (보어 역할) / along with + 동명사(~ing) = ~하는 것과 더불어
#27

It is possible / that no option will be clearly preferred / over the others.

→ 가능하다 / 어떤 선택지도 확실히 선호되지 않을 가능성이 / 나머지 것들보다.

★ 핵심 포인트: It (가주어) ~ that (진주어) / no + 명사 = 전체 부정
Ⅵ. 결론 — 완벽한 방식은 없다, 그러나 더 나은 결정을 향하여
#28

Instead of all methods pointing toward a single option / and making the council’s choice easier, / the winner differed / with each method.

→ 모든 방식들이 단 하나의 선택지를 가리키고 / 학생회의 선택을 더 쉽게 만들어 주는 대신에, / 우승자는 달랐다 / 각 방식에 따라.

★ 핵심 포인트: all methods (동명사의 의미상 주어) + pointing ~ and making (전치사 Instead of의 목적어인 동명사 병렬)
#29

All of these efforts are designed / not to make decision-making difficult and inefficient, / but to help us make better decisions / as a society.

→ 이 모든 노력들은 고안되었다 / 의사결정을 어렵고 비효율적으로 만들기 위해서가 아니라, / 우리가 더 나은 결정을 내리도록 돕기 위해 / 하나의 사회로서.

★ 핵심 포인트: be designed to-V = ~하도록 고안되다 / not A but B / help + O + 동사원형(make)
#30

Ultimately, / understanding all of the possible voting methods / and weighing their pros and cons / allows us to better understand / the process of decision-making.

→ 궁극적으로, / 가능한 모든 투표 방식들을 이해하는 것과 / 그 장단점을 따져 보는 것은 / 우리가 더 잘 이해하도록 해 준다 / 의사결정 과정을.

★ 핵심 포인트: understanding ~ and weighing = 동명사구 주어 병렬 (하나의 과정으로 보아 단수 동사 allows 사용) / allow + O + to-V
